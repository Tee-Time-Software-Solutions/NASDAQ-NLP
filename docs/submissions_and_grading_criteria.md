Criteria

I: Writing the Proposal (2%)

Objective: Define the project idea and scope.
Deliverables: A brief project proposal including objectives, expected outcomes, and resources needed.
Submission: Submit a brief pdf with the short description.
Grading Criteria: Clarity of objectives (1%), expected outcomes and resources (1%).
II: Literature Review (2%)

Objective: Conduct a literature review and gather information relevant to the project.
Deliverables: A summary of the literature review, including key findings and how they will inform your project.
Submission: Upload your pdf document in Turnitin
Grading Criteria: Relevance and comprehensiveness of the review (1%), integration of findings into the project (1%).
III: Methodology (2%)

Objective: Describe the methodology you will use in your project.
Deliverables: A detailed explanation of the methods and techniques you plan to use.
Submission: Upload your pdf document in Turnitin
Grading Criteria: Appropriateness of methods (1%), clarity and detail (1%).
IV: Introduction (2%)
Objective: Write the introduction section of your paper.
Deliverables: An introduction that outlines the project background, objectives, and significance.
Submission: Upload your pdf document in Turnitin
Grading Criteria: Clarity and coherence (1%), relevance to project objectives (1%).
V: Modelling (16%)

Submission: Upload all the following parts in a unique pdf document in Turnitin, except for the last part: The code documentation, which should preferable belong to a README file or in a separate pdf document

Data Collection & Cleaning
Objective: Collect and clean the data needed for your project.
Deliverables: A report on the data collection and cleaning process.
Grading Criteria: Completeness of data collection (1%), effectiveness of cleaning process (1%).
Preprocessing
Objective: Preprocess the data for your project.
Deliverables: A detailed report on the preprocessing steps taken.
Grading Criteria: Appropriateness and accuracy of preprocessing steps (1%), clarity of report (1%).
Feature Extraction
Objective: Extract features from the data.
Deliverables: A report on the feature extraction process.
Grading Criteria: Relevance and effectiveness of features extracted (1%), clarity of report (1%).
Modelling
Objective: Develop the model for your project.
Deliverables: A code notebook with the model implementation and preliminary results.
Grading Criteria: Correctness and complexity of model (2%), clarity of implementation (2%).
Evaluation
Objective: Evaluate the model using appropriate metrics.
Deliverables: A comprehensive evaluation report.
Grading Criteria: Appropriateness of evaluation metrics (1%), depth of analysis (1%).
Deployment
Objective: Deploy the model for practical use.
Deliverables: A report on the deployment process.
Grading Criteria: Effectiveness and thoroughness of deployment (1%), clarity of report (1%).
Code Documentation
Objective: Provide comprehensive documentation for the code.
Deliverables: Detailed code comments, a README file, and usage instructions.
Grading Criteria: Clarity and completeness of code documentation (1%), usability of instructions (1%).
VI: Results (2%)
Objective: Write the results section of the paper.
Deliverables: A comprehensive summary of the results.
Submission: Upload your pdf document in Turnitin
Grading Criteria: Clarity and coherence (1%), alignment with project objectives (1%).
VII: Abstract and Conclusion (2%)


Objective: Write the abstract and conclusion sections of the paper.
Deliverables: A concise abstract and a strong conclusion.
Submission: Upload your pdf document in Turnitin
Grading Criteria: Conciseness and clarity of abstract (1%), strength and coherence of conclusion (1%).
VIII: Project Submission and Presentation (2%)
Objective: Submit the final project and present it to the class.
Deliverables: The complete paper, code, code documentation, and a presentation summarizing your project, methodology, results, and conclusions.
Submission: Submit a .zip folder includes: The code, The code documentation, The paper .pdf and the presentation slides.
Grading Criteria: Clarity and effectiveness of presentation (2%).


IMPORTANT NOTES:

Failing to submit a part implies that no points will be received from it even if it is written in the final version of the paper
If a submission is submitted late, it will receive a penalization following this amounts: 10% from deadline to one day, 25% from one to two days, 50% from two to three days, 100% four days
